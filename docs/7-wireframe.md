# 사장님 MBTI 화면 와이어프레임

> 참고 문서: [`docs/3-PRD.md`](./3-PRD.md) (PRD), [`docs/4-user-scenario.md`](./4-user-scenario.md) (사용자 시나리오), [`docs/5-project-principle.md`](./5-project-principle.md) (프론트엔드 디렉토리 구조)

본 문서는 `docs/5-project-principle.md` 6절의 페이지 목록(LoginPage, SignupPage, MbtiTestPage, ResultPage, MyPage, PromotionListPage, AdminStatsPage, AdminPromotionManagePage)을 기준으로 각 화면의 레이아웃과 핵심 요소 배치를 텍스트 기반 ASCII 와이어프레임으로 정리한다. 픽셀 단위 목업이나 디자인 시스템(색상/폰트/컴포넌트)은 다루지 않는다.

PRD 5절 "반응형 웹 UI 필수 적용(모바일/데스크탑 대응)" 요구사항에 따라 화면 대부분을 모바일/데스크탑 두 폭 기준으로 그린다. 단, `AdminPromotionManagePage`는 표+폼 위주의 CRUD 화면이라 모바일 축소가 실익이 적어 데스크탑 레이아웃만 그린다(PRD 5절 "데스크탑에서 관리자 기능 사용" 전제와 일관, 접근 자체는 모바일에서도 차단하지 않음). 반응형 원칙은 다음 두 가지만 적용한다(브레이크포인트 이름, 그리드 시스템 등 구현 세부사항은 다루지 않음).

- 좁은 화면(모바일): 모든 요소를 1단 세로 배치
- 넓은 화면(데스크탑): 콘텐츠 폭을 제한한 카드를 중앙 정렬하거나 좌우 여백을 확보하고, 일부 항목(지표 카드, 통계 카드 등)은 가로로 나열

데스크탑 레이아웃은 모바일과 다른 화면을 새로 설계하는 것이 아니라, 같은 요소가 넓은 화면에서 어떻게 재배치되는지를 보여준다.

```
|  ------------------     |
```

```
|  (이하 스크롤로 전체 노출, 마지막 줄에 카드가 1개만 남아도 폭이 늘어나지 않고 1칸만 차지) |
+-------------------------+
```

로그인만 하면 검사 여부와 무관하게 접근 가능. 완료된 TestSubmission(최근 결과) 보유 시 매핑된 프로모션에 "추천" 뱃지가 붙고 목록 상단에 정렬됨(UC-3). "신규"는 등록일, "마감임박"은 마감일 기준으로 계산해 표시, TOP3에 포함된 항목은 "인기" 뱃지도 함께 표시하며, 매핑된 MBTI 유형은 뱃지로 함께 표시(도메인 정의서 8절 규칙). "인기 프로모션 TOP3" 각 카드에는 "1위"/"2위"/"3위" 순위 뱃지가 붙는다(v1.7). `[♡]`/`[♥]`는 북마크 토글 버튼(빈 하트=미북마크, 채워진 하트=북마크됨), 클릭 시 즉시 상태 전환. "프로모션 목록"은 "전체"/"신규"/"마감임박" 상태 버튼으로 필터링 가능(UC-3 5단계, 기존 MBTI 유형별 필터를 대체, v1.7에서 "상시" 버튼 제거) — 기본값은 항상 "전체"이다. "인기 프로모션 TOP3"는 이 필터 버튼 선택과는 무관하게 항상 본인 MBTI 유형(결과 없으면 전체) 기준을 유지한다(인기 프로모션 개인화 규칙).
