# 사장님 MBTI 화면 와이어프레임

> 참고 문서: [`docs/3-PRD.md`](./3-PRD.md) (PRD), [`docs/4-user-scenario.md`](./4-user-scenario.md) (사용자 시나리오), [`docs/5-project-principle.md`](./5-project-principle.md) (프론트엔드 디렉토리 구조)

본 문서는 `docs/5-project-principle.md` 6절의 페이지 목록(LoginPage, SignupPage, MbtiTestPage, ResultPage, MyPage, AdminStatsPage)을 기준으로 각 화면의 레이아웃과 핵심 요소 배치를 텍스트 기반 ASCII 와이어프레임으로 정리한다. 픽셀 단위 목업이나 디자인 시스템(색상/폰트/컴포넌트)은 다루지 않는다.

PRD 5절 "반응형 웹 UI 필수 적용(모바일/데스크탑 대응)" 요구사항에 따라 6개 화면 모두 모바일/데스크탑 두 폭 기준으로 그린다. 반응형 원칙은 다음 두 가지만 적용한다(브레이크포인트 이름, 그리드 시스템 등 구현 세부사항은 다루지 않음).

- 좁은 화면(모바일): 모든 요소를 1단 세로 배치
- 넓은 화면(데스크탑): 콘텐츠 폭을 제한한 카드를 중앙 정렬하거나 좌우 여백을 확보하고, 일부 항목(지표 카드, 통계 카드 등)은 가로로 나열

데스크탑 레이아웃은 모바일과 다른 화면을 새로 설계하는 것이 아니라, 같은 요소가 넓은 화면에서 어떻게 재배치되는지를 보여준다.

## 1. 로그인 화면 (LoginPage) — 모바일

```
+-------------------------+
|      사장님 MBTI         |
|                         |
|  이메일                  |
|  [______________]      |
|                         |
|  비밀번호                |
|  [______________]      |
|                         |
|     [   로그인   ]        |
|                         |
|  아직 계정이 없으신가요?    |
|     [ 회원가입 ]          |
+-------------------------+
```

이메일/비밀번호 입력 후 로그인 버튼 클릭 → 성공 시 메인/테스트 화면 진입, 실패 시 오류 메시지 표시. 회원가입 링크로 SignupPage 이동.

## 3. MBTI 테스트 화면 (MbtiTestPage) — 모바일

### 3-1. 진행 중 상태 (12문항 중 일부 응답)

```
+-------------------------+
|  사장님 MBTI 테스트         |
|  진행률 [====------] 4/12 |
|                         |
|  Q4. 새로운 메뉴를          |
|  자주 시도하는 편이다        |
|                         |
|     [ 예 ]   [ 아니오 ]    |
|                         |
|  (이전 문항 목록/스크롤)     |
|                         |
|   [   제출하기 (비활성)  ]  |
+-------------------------+
```

### 3-2. 12문항 미완료 상태 (제출 버튼 비활성화)

```
+-------------------------+
|  사장님 MBTI 테스트         |
|  진행률 [========--] 8/12 |
|                         |
|  Q9. 손님 응대는            |
|  매뉴얼대로 하는 편이다       |
|                         |
|     [ 예 ]   [ 아니오 ]    |
|                         |
|  미응답 문항: 4개           |
|   [ 제출하기(비활성/회색) ] |
+-------------------------+
```

### 3-3. 12문항 완료 상태 (제출 버튼 활성화)

```
+-------------------------+
|  사장님 MBTI 테스트         |
|  진행률 [==========] 12/12|
|                         |
|  모든 문항에 응답했습니다.    |
|                         |
|     [   제출하기   ]      |
+-------------------------+
```

문항 카드(QuestionCard)에 예/아니오 응답, 진행률 표시. 12문항 전부 응답 전에는 제출 버튼이 비활성화되고, 완료 시에만 활성화되어 제출 → 결과 판정 요청(시나리오 4 예외 케이스 반영).
