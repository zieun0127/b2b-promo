# 사장님 MBTI 도메인 정의서 (초안)

## 1. 개요

"사장님 MBTI"는 외식사업자를 대상으로 MBTI 테스트 기반 참여형 이벤트를 제공하는 웹 애플리케이션이다.

외식사업자는 매장 운영 성향(메뉴 운영, 고객 응대, 비용 관리, 신메뉴 도입 방식 등)에 따라 필요한 정보와 조언이 다르지만, 이를 쉽게 확인할 수 있는 콘텐츠가 부족하고, 운영자 입장에서도 고객의 성향을 자연스럽게 파악할 접점이 부족하다. 본 서비스는 흥미 위주의 MBTI 테스트로 참여를 유도하고, 결과에 맞는 장사 TIP과 추천 프로모션을 제공하여 실질적인 도움을 주는 동시에, 관리자에게는 참여 고객의 성향 분포를 파악할 수 있는 통계를 제공한다.

또한 MBTI 테스트는 1회성 참여로 끝나기 쉬우므로, 운영자가 지속적으로 프로모션을 등록/갱신하고 사용자가 이를 주기적으로 확인·관심 표시(북마크)하도록 하여 재방문을 유도한다(v1.6, 프로모션 상시 노출 기능 추가).

## 2. MVP 범위

### 포함 (In Scope)
- 회원가입 및 로그인(인증) 후 서비스 이용
- 외식업 운영 상황 기반 예/아니오 질문에 대한 답변 → E/I, S/N, T/F, J/P 판별 → 16개 유형 중 1개 결과 도출 (규칙 기반)
- MBTI 유형별 설명, 장사 TIP/간단 솔루션 제공
- MBTI 유형별 추천 프로모션 정보 노출 (표시 전용, 실제 쿠폰 발급/사용/결제는 제외)
- **이벤트/프로모션 목록 상시 조회**: 로그인한 사용자는 등록된 전체 프로모션을 언제든 목록으로 조회 가능. MBTI 검사를 완료한 사용자는 자신의 유형에 매핑된 프로모션이 목록 상단에 추천으로 정렬됨 (v1.6)
- **프로모션 관심 표시(북마크)** 및 북마크 수 기반 인기 프로모션 노출 (v1.6)
- **관리자의 프로모션 등록/수정/삭제**(CRUD) 및 MBTI 유형 매핑 관리 (v1.6, 기존에는 시드 데이터로만 존재하던 참조 데이터를 관리자가 직접 운영)
- 계정별 테스트 참여 이력 저장 및 마이페이지에서 **참여 이력 전체 및 북마크 목록** 조회 (v1.6, 기존 "최근 결과 1건"에서 확장)
- 관리자용 참여 현황 통계(전체 참여자 수, 유형별/성향 지표별 참여자 수 및 비율, **프로모션별 추천 매칭 수·북마크 수**)
- 모바일에서 테스트 참여, 데스크탑에서 관리자 통계 조회가 가능한 반응형 UI (상세 UI 설계는 본 문서 범위 밖)

### 제외 (Out of Scope, MVP 제외)
- 실제 상품 주문/결제
- 실제 프로모션 쿠폰 발급
- 포인트 적립
- 외부 쇼핑몰 연동
- POS 연동
- 매출 데이터 자동 연동
- AI 기반 정교한 개인화 추천 기능
- 프로모션 조회수/클릭 로그 추적 (인기도는 북마크 수로만 판단, v1.6)
- 프로모션 이미지/첨부파일 업로드 (텍스트 정보만 등록)
- 알림(이메일/푸시) 발송 — 신규/마감임박 표시는 화면 내 뱃지로만 제공, 별도 발송 채널 없음

## 3. 핵심 액터

| 액터 | 설명 |
|---|---|
| 외식사업자(회원, PRD상 "거래처"와 동일 대상) | 회원가입/로그인 후 MBTI 테스트에 참여하고 결과 및 장사 TIP을 확인하는 사용자 |
| 관리자 | 이벤트 참여 현황 및 성향 통계를 조회하는 운영자 |

## 4. 핵심 도메인 엔티티

### User (사용자)
- 설명: 회원가입한 계정. 외식사업자 또는 관리자 역할을 가짐.
- 주요 속성: id, email, password(해시), 역할(role: USER/ADMIN), 생성일시
- 인증 방식은 PRD 5절 참조 (JWT Access/Refresh Token, Refresh Token은 서버 저장 없이 stateless로 처리)
- 상태값: 없음 (활성 계정만 가정, 탈퇴/휴면 등은 MVP 제외)

### MbtiQuestion (MBTI 질문)
- 설명: 예/아니오로 답변하는 테스트 문항. 4개 성향 지표 중 하나를 판별하기 위한 문항.
- 주요 속성: id, 질문 내용, 대상 지표(E/I, S/N, T/F, J/P 중 하나), "예" 응답 시 판정되는 성향값
- 문항 수: 지표당 3문항, 총 12문항 (완료 판정 기준)
- 상태값: 없음

### MbtiResultType (MBTI 유형 정의)
- 설명: 16개 유형 각각에 대한 외식사업자 관점 설명 및 장사 TIP을 담은 참조 데이터
- 주요 속성: 유형 코드(예: ENTJ), 유형 설명, 장사 TIP/솔루션 텍스트

### PromotionOffer (이벤트/프로모션)
- 설명: MBTI 유형별로 추천되는 프로모션 소개 정보. 실제 쿠폰 발급/사용/결제 없이 표시 전용으로 제공되지만, **관리자가 직접 등록/수정/삭제하는 관리 대상 엔티티**(v1.6, 기존에는 시드 데이터로만 존재하는 순수 참조 데이터였음)
- 주요 속성: id, 프로모션명, 설명, 등록일시(created_at), 마감일시(ends_at, 선택값 — 없으면 상시 프로모션), 대상 MBTI 유형(1개 이상, N:N 매핑은 기존과 동일)
- "신규"/"마감임박" 표시는 UI 레벨에서 `created_at`/`ends_at` 값을 기준으로 판단하며 별도 상태값을 저장하지 않는다

### Bookmark (프로모션 관심 표시) — v1.6 신규
- 설명: 사용자가 특정 프로모션에 관심을 표시(북마크)한 기록. 사용자는 언제든 켜고 끌 수 있는 토글이며 이력을 누적하지 않는다(TestSubmission과 달리 최신 상태만 존재).
- 주요 속성: user_id, promotion_offer_id, 북마크한 일시
- 용도: ① 마이페이지의 "북마크한 프로모션" 목록, ② 프로모션 목록의 "인기 프로모션" 정렬(북마크 수 기준), ③ 관리자 통계의 프로모션별 북마크 수

### TestSubmission (테스트 참여 기록)
- 설명: 사용자가 1회 테스트에 참여한 결과를 저장하는 엔티티. 사용자별 이력으로 누적됨.
- 주요 속성: id, user_id, 참여일시, 각 문항별 답변 목록(또는 4개 지표 최종값 E/I·S/N·T/F·J/P), 산출된 mbti_result_type
- 상태값: 완료(COMPLETED) / 미완료(IN_PROGRESS) — 미완료 상태는 결과 미생성 처리를 위한 상태이며, 필요 시 임시 저장 없이 미제출로 간주해도 무방함(구현 단순화 가능)

## 5. 엔티티 관계

- User 1 : N TestSubmission (한 사용자는 여러 번 테스트에 참여 가능, 이력 누적)
- TestSubmission N : 1 MbtiResultType (하나의 참여 기록은 하나의 MBTI 유형 결과를 가짐)
- MbtiResultType N : N PromotionOffer (하나의 MBTI 유형에 1개 이상의 추천 프로모션이 매핑될 수 있음)
- MbtiQuestion은 TestSubmission과 직접 연관되기보다, 답변 로그를 통해 간접 참조됨 (답변 로그 저장은 MVP에서 간소화하여 4개 지표 최종값만 저장해도 무방함)
- User N : N PromotionOffer, Bookmark를 통해 표현 (v1.6) — 한 사용자가 여러 프로모션을 북마크할 수 있고, 한 프로모션은 여러 사용자에게 북마크될 수 있음. TestSubmission과 달리 이력이 아닌 현재 상태(북마크함/안 함)만 의미가 있으므로 (user_id, promotion_offer_id) 조합은 유일해야 함

## 6. 주요 유스케이스

### UC-1. 외식사업자의 MBTI 테스트 참여 및 결과/장사 TIP/추천 프로모션 확인
- 액터: 외식사업자(회원)
- 트리거: 로그인한 사용자가 "MBTI 테스트 시작" 버튼 클릭
- 흐름:
  1. 시스템이 MBTI 판별용 질문 목록을 제시
  2. 사용자가 각 질문에 예/아니오로 답변
  3. 사용자가 제출
  4. 시스템이 답변 조합으로 E/I, S/N, T/F, J/P 각 지표를 판정하고 16개 유형 중 하나를 결정
  5. 시스템이 TestSubmission을 저장(완료 상태)하고 결과 화면에 유형, 설명, 장사 TIP, 해당 유형에 매핑된 추천 프로모션을 표시
- 결과: 사용자 계정에 테스트 참여 이력 및 MBTI 결과가 저장되고, 결과 화면 및 마이페이지에서 확인 가능

### UC-2. 관리자의 이벤트 참여 현황 및 고객 성향 통계 조회
- 액터: 관리자
- 트리거: 관리자가 관리자 화면 접속
- 흐름:
  1. 시스템이 전체 참여자 수(완료된 TestSubmission 수) 집계
  2. MBTI 유형별 참여자 수 및 비율 집계
  3. E/I, S/N, T/F, J/P 각 성향별 참여자 비율 집계
  4. 프로모션별 추천 매칭 수(해당 프로모션이 매핑된 MBTI 유형으로 판정된 완료 TestSubmission 수) 및 북마크 수 집계 (v1.6)
  5. 관리자에게 통계 화면 표시
- 결과: 관리자가 이벤트 참여 현황, 고객 성향 분포, 프로모션별 반응을 확인 가능 (통계는 집계용이며 과학적 성향 분석 목적 아님)

### UC-3. 외식사업자의 이벤트/프로모션 목록 조회 및 관심 표시 (v1.6 신규)
- 액터: 외식사업자(회원)
- 트리거: 로그인한 사용자가 "이벤트/프로모션" 메뉴 진입
- 흐름:
  1. 시스템이 등록된 전체 PromotionOffer 목록을 조회
  2. 사용자가 완료된 TestSubmission(최근 결과)을 보유한 경우, 해당 MBTI 유형에 매핑된 프로모션을 목록 상단에 "추천"으로 정렬
  3. 북마크 수 기준 상위 3개를 "인기 프로모션"으로 별도 노출
  4. 각 프로모션에 등록일 기준 "신규", 마감일 임박 기준 "마감임박" 뱃지를 표시
  5. 사용자가 "전체" 또는 16개 MBTI 유형 버튼 중 하나로 목록을 필터링(v1.7). 완료된 결과가 있으면 최초 진입 시 자신의 유형이 기본 선택되고, 결과가 없으면 "전체"가 기본 선택됨. "인기 프로모션" 섹션은 이 필터와 무관하게 항상 전체 기준으로 노출
  6. 사용자가 프로모션에 관심 표시(북마크) 버튼을 눌러 켜거나 끔
- 결과: 사용자는 검사 여부와 무관하게 프로모션을 상시 조회할 수 있고, 관심 있는 유형만 걸러볼 수 있으며, 북마크한 프로모션은 마이페이지에서 다시 확인 가능

### UC-4. 관리자의 프로모션 등록/수정/삭제 (v1.6 신규)
- 액터: 관리자
- 트리거: 관리자가 "프로모션 관리" 화면 진입
- 흐름:
  1. 시스템이 등록된 전체 PromotionOffer 목록을 관리 화면에 표시
  2. 관리자가 신규 프로모션(이름, 설명, 마감일, 대상 MBTI 유형 1개 이상)을 등록
  3. 관리자가 기존 프로모션의 정보 또는 MBTI 유형 매핑을 수정
  4. 관리자가 더 이상 노출하지 않을 프로모션을 삭제
- 결과: 등록/수정/삭제된 내용이 즉시 UC-3의 사용자 목록과 UC-1의 추천 프로모션에 반영됨

## 7. 예외 케이스

- 테스트 응답이 모든 질문(총 12문항)에 답변되지 않은 경우, 제출 버튼을 비활성화하여 제출 자체를 차단한다 (완료된 제출만 통계 및 마이페이지에 반영).
- 로그인하지 않은 사용자가 테스트 페이지에 접근하는 경우, 로그인 화면으로 이동시킨다.
- 일반 사용자가 관리자 화면(통계 조회, 프로모션 관리)에 접근하는 경우, 접근을 차단한다 (역할 기반 접근 제어).
- MBTI 검사 이력이 없는 사용자가 프로모션 목록을 조회하는 경우, 추천 정렬 없이 등록순(또는 인기순)으로만 노출한다(에러 아님, v1.6).
- 이미 북마크한 프로모션을 다시 북마크 요청하는 경우, 중복 저장하지 않고 멱등하게 처리한다(토글 결과만 최신 상태 반영, v1.6).
- 관리자가 대상 MBTI 유형을 1개도 지정하지 않고 프로모션을 등록하려는 경우, 등록을 거부한다(추천 로직이 성립하지 않으므로, v1.6).
- 관리자가 프로모션을 삭제하면 해당 프로모션에 대한 Bookmark와 MbtiResultType 매핑도 함께 제거한다(과거 TestSubmission 결과 자체는 영향받지 않음, v1.6).

## 8. 비즈니스 규칙

- MBTI 결과 산출은 4개 성향 지표(E/I, S/N, T/F, J/P) 각각에 대한 답변 조합을 기반으로 하는 단순 규칙 기반 로직이며, 통계적/심리학적 정밀 분석이 아닌 흥미 위주 이벤트 콘텐츠임을 전제로 한다.
- 재참여 규칙: 동일 사용자는 테스트에 여러 번 참여할 수 있으며, 참여할 때마다 새로운 TestSubmission을 이력으로 누적 저장한다(기존 결과를 덮어쓰지 않음). 마이페이지에는 가장 최근 결과를 기본으로 표시한다. 이력으로 남기는 이유는 관리자 통계가 특정 시점의 스냅샷이 아닌 누적 참여 데이터를 기반으로 하기 때문이다.
- 완료되지 않은 TestSubmission(모든 질문에 답변하지 않음)은 결과가 생성되지 않으며, 관리자 통계 집계 대상에서 제외한다.
- 관리자 통계는 이벤트 참여 결과의 단순 집계(카운트, 비율)를 제공하는 용도이며, 실제 고객 성향에 대한 과학적/심리학적 분석 결과가 아님을 명시한다.
- MBTI 유형별 설명 및 장사 TIP은 고정된 참조 데이터(MbtiResultType)로 관리하며, 사용자별 실시간 개인화 로직(AI 추천 등)은 MVP에 포함하지 않는다.
- 프로모션 추천 규칙: MBTI 유형에 대해 고정된 규칙 기반 매핑(MbtiResultType-PromotionOffer)으로 추천 프로모션을 노출하며, 실제 쿠폰 발급/사용/결제 처리는 하지 않는다(표시 전용). AI 기반 개인화 추천은 MVP에 포함하지 않는다.
- 프로모션 관리 규칙(v1.6): PromotionOffer는 관리자만 등록/수정/삭제할 수 있다(일반 사용자는 조회와 북마크만 가능). 마감일(`ends_at`)이 지난 프로모션도 자동 삭제/숨김 처리하지 않으며, 목록에는 계속 노출하되 "마감" 표시만 추가한다(운영 판단으로 관리자가 직접 삭제).
- 프로모션 정렬 규칙(v1.6): 목록은 ①추천 여부(로그인 사용자의 최신 완료 결과 유형과 매핑 일치) → ②등록일 내림차순을 기본 정렬로 하며, "인기 프로모션" 섹션은 북마크 수 내림차순 상위 3개를 별도로 보여준다. 조회수/클릭 기반 랭킹은 MVP에서 계산하지 않는다(북마크 수로 대체).
- 프로모션 유형 필터 규칙(v1.7): 목록 화면에 "전체"와 16개 MBTI 유형 버튼을 제공해 사용자가 원하는 유형만 걸러볼 수 있다. 필터는 클라이언트에서 `mbti_type_codes` 포함 여부로만 계산하며 별도 API를 두지 않는다. 최초 진입 시 기본값은 완료된 결과가 있으면 자신의 유형, 없으면 "전체"이다. "인기 프로모션" 섹션은 이 필터의 영향을 받지 않는다.
- 북마크 규칙(v1.6): 북마크는 사용자별 현재 상태만 저장하며(이력 누적 아님), MBTI 검사 여부와 무관하게 로그인만 하면 가능하다.
