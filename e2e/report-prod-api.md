# 운영 배포 백엔드 API E2E 테스트 리포트

- **대상**: `https://mbti-127-be.vercel.app` (실제 배포된 운영 백엔드, 운영 DB: Supabase)
- **일시**: 2026-08-21
- **방식**: API 레벨 E2E (브라우저 UI 아님)
- **왜 API 레벨인가**: 프론트엔드는 아직 Vercel에 배포되지 않았고, 운영 백엔드의 CORS(`Access-Control-Allow-Origin: https://mbti-127-fe.vercel.app`)가 로컬(`localhost`) origin의 브라우저 요청을 차단한다. 따라서 화면 기반 E2E는 현재 불가능하며, `docs/4-user-scenario.md`의 각 시나리오 단계를 실제 API 호출 시퀀스로 재현해 검증했다.
- **테스트 스크립트**: 세션 임시 디렉토리의 `e2e-prod-api.mjs` (Node 내장 `fetch` 사용, 저장소에는 커밋하지 않음 — 1회성 검증 스크립트)

## 발견된 이슈

- **애플리케이션 버그 없음.** 33건 모두 기대한 상태 코드/응답 형태로 동작했다.
- **배포 구성 이슈 (별건, 이번 대화 중 별도 보고·조치)**: `frontend/.env.production`의 `VITE_API_BASE_URL`에 오타(`mbit-127-be` → `mbti-127-be`)가 있었음(로컬 파일은 수정 완료, 커밋 대상 아님이라 Vercel 환경변수는 별도 반영 필요). 프론트엔드 자체가 Vercel에 아직 배포되지 않아 실제 브라우저 E2E는 수행하지 못함.
