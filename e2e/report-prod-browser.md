# 운영 배포(프론트+백엔드) 브라우저 E2E 테스트 리포트

- **프론트엔드**: `https://mbti-127-fe.vercel.app` (Vercel 배포, SPA fallback 적용 확인)
- **백엔드**: `https://mbti-127-be.vercel.app` (운영 DB: Supabase)
- **일시**: 2026-08-21
- **방식**: Playwright MCP로 실제 배포 URL에 접속해 브라우저 조작 (CORS 정상 동작 확인 — 콘솔에 CORS 에러 없음)

## 결과 요약

`docs/4-user-scenario.md` 시나리오 1~9 + 접근 제어(6-1/6-2) + 예외 케이스 + 모바일 반응형 + 신청 기능(v1.10, 문서 미반영) 전부 PASS. 애플리케이션 버그 없음.

| 시나리오 | 결과 | 확인 내용 |
|---|---|---|
| 1. 회원가입→로그인→MBTI 테스트→결과 확인 | PASS | 12문항 응답→제출→ESTJ 판정, 유형 설명/장사 TIP/추천 프로모션 2건(유형당 프로모션 확장 반영) 표시 |
| 2. 마이페이지 최근 결과 조회 | PASS | 방금 결과가 마이페이지에 그대로 표시 |
| 3. 재참여(이력 누적, 최신 결과 갱신) | PASS | 재제출 시 새 유형(INTP) 산출, 마이페이지 최근 결과 갱신, 참여 이력에 ESTJ/INTP 2건 최신순 누적 |
| 4. 미완료 제출 예외 | PASS | 0/12~11/12 구간 내내 "제출하기" 버튼 비활성화, 12/12에서만 활성화 |
| 5. 관리자 참여 현황/성향 통계 | PASS | 전체 참여자 수, 16유형별 비율, 4개 지표별 비율 정상 표시 |
| 6-1. 비로그인 접근 차단 | PASS | localStorage 초기화 후 `/mypage` 접근 시 `/login`으로 리다이렉트 |
| 6-2. 일반 사용자 관리자 화면 접근 차단 | PASS | `/admin/stats` 직접 접근 시 홈(`/`)으로 리다이렉트 |
| 7. 프로모션 목록 조회 및 북마크 | PASS | TOP3 순위 뱃지, 추천/신규/마감임박/인기 뱃지 정상, 북마크 등록 시 하트 카운트·상태 즉시 반영 |
| 8. 마이페이지 참여 이력 + 북마크 목록 | PASS | 이력 2건, 북마크한 프로모션이 목록에 정상 표시 |
| 9. 관리자 프로모션 등록/수정/삭제 | PASS | 등록 즉시 목록 반영 → 수정 반영 → 삭제 후 즉시 제거 |
